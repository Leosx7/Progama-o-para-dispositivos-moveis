# Atividade 03 — Classes, construtores e herança

Baseada nas atividades das páginas 11, 14 e 17 do material **Classes**, do Prof. Otilio Paulo.

## Arquivos
- `exemplo_01_classes.dart`: cria as classes `Carro` e `Aviao` e atribui valores depois de criar os objetos.
- `exemplo_02_construtores.dart`: usa construtores para receber velocidade, cor e peso.
- `exemplo_03_heranca.dart`: cria `Veiculo`; `Carro` e `Aviao` herdam seus atributos, e `Aviao` ganha `numeroHelices`.

## Como executar
Abra o terminal **dentro desta pasta**:
```bash
dart run exemplo_01_classes.dart
dart run exemplo_02_construtores.dart
dart run exemplo_03_heranca.dart
```

## Para explicar ao professor
**Classe** é um modelo para criar objetos; **atributo** é uma informação do objeto; **objeto** é uma instância da classe; **construtor** preenche valores ao criar o objeto; **herança** permite reaproveitar atributos. `extends` indica a herança e `super` chama o construtor da classe-base.

Os valores de exemplo foram escolhidos apenas para demonstrar o código, não representam modelos reais de veículos.
